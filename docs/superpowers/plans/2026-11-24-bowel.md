# 食管与结肠 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `esophagus` 食团转运与呛咳、`colon` 残渣水回收/粪便/便意全链接入；根清单 34 部位 / 36 参数、女性 36 / 38。

**Architecture:** `esophagus` 记录食团与转运时延、呛咳进 `interoception.discomfort`；`smallIntestine.waterVolumeMl` 增加 `transferOut: ['colon.residueWaterMl']`，`colon` 回收水回流 `bodyFluid`、形成粪便，`defecate` 动作排出并产生便意。

**Tech Stack:** Node >=22.18、ESM、本地可擦除 TypeScript、`node:test` + `node:assert`，无第三方依赖。

**Spec:** `docs/superpowers/specs/2026-11-24-bowel-design.md`

## Global Constraints

- 后台子代理分片修改；本批不 commit、不 push，保留根目录大型传输归档。
- 分片只改自己列出的文件；不改 plan/spec；所有新参数 `design`、`source: null`。
- 不做肠道菌群、消化酶、纤维发酵、气体/腹胀、直肠肛门细节、绝对转运时间。
- 每轮只读轮初快照与本轮原始动作；`dtMin = io.dt / 60`；可选部位未加载按 spec 回退，非法上游抛错使本轮失败。
- 状态 JSON-safe；`fields` 每字段声明 `unit` 与 `mode`；文档中文，区分"当前实现 / 未建模 / 未验证"。
- 临时产物只放 `mktemp -d /tmp/dsh-body/<任务>.XXXXXX`。
