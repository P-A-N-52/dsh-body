# 胰腺相对胰岛素信号与葡萄糖清除调节设计

**状态：** 已实现并完成离线验收（2026-11-23）。用户已明确可以并行制作多个器官/功能薄切片；具体方程、参数和分片方式为本轮设计决策。共享 JSON 状态交互即可，不要求行为闭环。最终验证与未验收边界见 [`2026-11-23-parallel-organ-slices.md`](../plans/2026-11-23-parallel-organ-slices.md)。

**后续（2026-11-23）：** 胰腺与肾糖已并行接入，根清单最终为 15 部位、18 份参数文件；本设计保留单独胰腺切片“13 增至 14”的当时拆分口径。

## 1. 目标与边界

建立：

```text
glucose.concentrationMgDl
  → pancreasEndocrine.insulinRelative
  → glucose 超基线表观清除速率
```

目标是让胰腺内分泌信号真正改变葡萄糖轨迹，而不是只新增一个展示字段。`insulinRelative = 1` 是基础相对信号，不是 µU/mL、pmol/L、分泌率或实测血浆浓度。

- 胰腺只写相对信号；葡萄糖仍是自己三个字段的唯一写者。
- 无胰岛素 transfer，不搬质量；双方只读轮初快照，不做同轮迭代。
- 基线时精确复用现有 60 min 表观清除公式；高信号加快、低信号减慢，清除不超过超基线质量。
- 不建肝糖、胰高血糖素、两室胰岛素、组织分区、饱和作用、胰岛素抵抗或自动行为。肾糖是另一独立薄切片，不在本设计中。

## 2. 方案取舍

### 选择：一个相对状态的一阶目标响应

胰腺以血糖偏差形成目标相对信号，再以一阶指数趋近；葡萄糖按相对信号缩放清除速率。它只有一个新部位字段，能表达餐后上升和回落，基线兼容明确。

### 不采用

- **只产胰岛素读数：** 不改变任何状态计算，价值不足。
- **静态血糖映射：** 没有记忆和回落过程。
- **显式分泌/清除两个速率或两室胰岛素：** 参数和证据要求更高，本切片不需要。
- **直接以血糖缩放清除、跳过胰腺：** 失去器官关系和未来抵抗/药物等读取接口。
- **同时加入肝糖：** 会引入内源葡萄糖来源、新的质量账和空腹稳态，超出本切片。

## 3. 部位与参数

新部位：

| 项 | 契约 |
| --- | --- |
| 部位 ID | `pancreasEndocrine` |
| 脚本 | `organs/human-organs/pancreas/insulin.ts` |
| 参数 | 同目录 `insulin.parameters.json` |
| 字段 | `insulinRelative`，单位 `1`，`absolute`，初值 1 |
| 动作 / transfer / 通知 | 均无 |
| 消费者 | `glucose` 的表观清除计算 |

根清单由 13 增至 14 个部位。未来胰腺外分泌可另立独立状态和写者，不改此 ID。

新参数全部为 `design`、`source: null`：

| 参数 ID | 默认值 | 单位 | 替换点 |
| --- | ---: | --- | --- |
| `pancreasEndocrine.referenceGlucoseMgDl` | 90 | `mg/dL` | 未来由共享身体预设/个体空腹基线替换 |
| `pancreasEndocrine.insulin.glucoseGainPerMgDl` | 0.02 | `1/(mg/dL)` | 未来由标准化餐后胰岛素剂量—反应替换 |
| `pancreasEndocrine.insulin.responseHalfTimeMin` | 10 | `min` | 未来由 C-peptide/胰岛素分泌与清除证据替换 |
| `pancreasEndocrine.insulin.maxRelative` | 5 | `1` | 工程上限；未来由饱和 β 细胞响应替换 |

这些数值不是人体测量、文献报告值或拟合结果。`referenceGlucoseMgDl` 暂时与 `glucose.baselineConcentrationMgDl` 重复配置，测试固定两者相等；不跨模块 import 对方参数文件，未来由共享身体预设统一。

`glucose.apparentDisposalHalfTimeMin = 60 min` 的 ID 和值不变，语义改为“`insulinRelative = 1` 时的基线表观清除半时”。不新增葡萄糖参数。

## 4. 离散方程与轮次

设 `dtMin = io.dt / 60`，胰腺读取轮初 `G = glucose.concentrationMgDl` 和自身轮初 `I`：

```text
target = clamp(1 + 0.02 × (G − 90), 0, 5)
I_next = target + (I − target) × 2^(−dtMin / 10)
write.insulinRelative = I_next
```

`G = 90` 且 `I = 1` 时精确保持 1。高糖提高目标，低糖可降低目标但不低于 0；该方程只描述工程相对信号，不区分分泌增加和清除变化。

葡萄糖读取轮初 `I = pancreasEndocrine.insulinRelative`：

```text
E = max(0, M_start − B)
D = E × (1 − 2^(−dtMin × I / 60))
write.glucoseMassG = M_start − D
write.disposedGlucoseG = D
write.concentrationMgDl = M_start × 1000 / V
```

`B`、`V` 和浓度定义沿用碳水薄切片。`I = 1` 与原公式完全一致；`I > 1` 时 `D` 增大，`0 <= I < 1` 时减小，`I = 0` 时停止超基线清除。始终 `0 <= D <= E`，不会把质量压到基线以下，也不引入低基线补糖。

这是把现有聚合清除整体按相对信号缩放的工程简化，不表示所有组织摄糖都依赖胰岛素。原文中的胰岛素非依赖利用和饱和远端作用没有在本切片分建。

### 默认轮次

一次摄入沿用第 1 轮入胃、第 2 轮胃排入小肠、第 3 轮首次吸收、第 4 轮首次高浓度读数：

- 第 4 轮胰腺仍读到旧 90 mg/dL，写 1。
- 第 5 轮胰腺读到高浓度，写 `I > 1`；葡萄糖本轮仍使用轮初 `I = 1`。
- 第 6 轮葡萄糖第一次使用高相对信号，清除开始加快。

不存在同轮“血糖升 → 胰岛素升 → 清除升”的代数环。

## 5. 缺失、异常与旧档

必须区分“上游按设计未接入”和“已接入但异常”：

- 自定义清单没有 `pancreasEndocrine` 时，葡萄糖按 `I = 1` 使用既有固定清除，保持清单可替换性。
- 自定义清单没有 `glucose` 时，胰腺按 `G = 90` 保持基础信号。
- 部位已加载但所需读数字段缺失、非有限或为负数时，不得用健康常量掩盖；让本轮失败并暴露错误。合法 0 是有效低信号，不是缺失。
- 旧根存档只补 `pancreasEndocrine.insulinRelative = 1`，不反推升级前胰岛素，也不重置已有葡萄糖。第一轮仍按旧公式清除，后续再响应。
- 重启保留已提交相对信号；不从当前血糖反推历史。

## 6. 证据边界

Dalla Man 2007（已登记 `SRC-DALLAMAN-2007`）只作结构背景：其 p.1742–1745 描述胰岛素动力学、葡萄糖依赖分泌、延迟作用和组织利用，p.1748 明确为平均模型。现有笔记可扩展这些定位，但不复制第二份笔记。

当前一阶目标、线性清除缩放、0.02 增益、10 min 半时和 5 倍上限都不是原文方程或参数，保持 `design`、`source: null`。原文的胰岛素非依赖利用、两室动力学和饱和作用没有被复现；不能称 `fitted_dev`、`validated`、正常餐后曲线或个体预测。

## 7. 验收

1. **胰腺模块：** 契约、基线恒 1、高糖上升并趋近目标、低糖有界下降、缺失上游回退、异常读数失败、JSON-safe。
2. **葡萄糖耦合：** `I=1` 精确旧公式；同一质量下 `D(2)>D(1)>D(0.5)>D(0)=0`；基线/低基线不补糖；缺失胰腺回退，异常胰腺报错。
3. **真实根清单：** 无碳水长期保持基线；60 g 场景第 4 轮浓度升、第 5 轮胰岛素升、第 6 轮首次加快清除；外源碳水质量账仍 ≤`1e-6 g`。
4. **重启与旧档：** 餐后重启保留胰岛素，旧档从 1 开始；无胰腺自定义清单保持原葡萄糖轨迹。
5. **回归：** 根清单/部位计数更新为 14；原水账、DI、通知和既有生理断言不回归。运行完整 `npm test` 和 `git diff --check`。
6. **边界：** 真实 DSH、长期独立曲线、餐后胰岛素测量和临床验证不在本轮；不能用已看过的论文数据声称独立验证。

## 8. 后续替换

- 有可靠餐后胰岛素与 C-peptide 证据后，再考虑分泌/清除分离或两室信号。
- 有作用剂量—反应证据后，再考虑胰岛素非依赖份额和饱和项。
- 肝糖需要独立的内源质量账、基础周转和空腹触发设计；不因本切片完成而自动解锁。
