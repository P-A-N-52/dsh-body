# 感觉器

M1 从胃充盈信号开始。感觉器负责把胃模块提供的内容量映射为充盈信号，神经系统把这个信号和饥饿素作用一起转为体感。

优先找同时测量胃容积与充盈或饱胀评分的人体实验。摘录刺激条件、体积单位、量表两端的含义，以及同一体积下反应的差异。饥饿与饱胀两项评分在笔记中分别保留。[胃内容量](../digestive/README.md) · [体感整合](../nervous/README.md)

M1 饱感数据与量表的候选来源见 [Camps 2016 笔记](../digestive/references/notes/camps-2016.md)和[共享登记簿](../digestive/references/source-index.csv)。
