# 消化系统

M1 从胃开始。胃模块负责胃内容量、每轮排空量和已经入胃的餐食记录。进食体积用 mL，能量用 kcal。感觉器读取更新后的胃内容量。

优先找给出餐后胃内容量或胃残留比例随时间变化的人体实验。摘录餐型、固液组成、摄入体积和能量、测量方法、曲线的时间点。遇到百分比，要记清分母，才能判断这条曲线能否用于“半块蛋糕”的算例。[胃充盈信号](../sensory/README.md)
