## 1. 能回答的问题

20–80 岁健康久坐男女在快速递增运动中，`VE = 20–80 L/min` 范围内 `VT` 与 `fR`（呼吸频率）如何协同演变？

## 2. 设计与受试者

- 人群：$n = 120$ 名健康久坐成人（`60` 男、`60` 女，按 `20–80` 岁分 `6` 组每组 `n = 20`；`20–39` 岁男 BMI `25.2 ± 3.3`、女 `27.5 ± 8.2 kg/m²`）。
- 协议：快速递增功率车试验至力竭。
- 核心结果：
  - `VT/IC` 随 `VE` 呈曲线递升并趋向平台（无性别比值差异，绝对 `VT` 女性低于男性，`P < 0.05`）。
  - 青年/中青年男性在 `VE = 20 L/min` 时，实测 `fR/VT` 为 **`18.9 ± 6.1`** 与 **`18.5 ± 6.6 breaths/(min·L)`**（即约 `VT ~ 1.0–1.1 L`、`RR ~ 18–20 breaths/min`，远非固定 `500 mL × 40/min`）。
  - `TI` 随负荷线性缩短，`TE` 呈曲线缩短；仅 `20–39` 岁女性组普遍达到 `VE = 80 L/min`。

## 3. 局限与不可推论边界

- 仅限久坐未受训成人；摘录缺失原文 Table 2/3 全部 `20/40/60/80 L/min` 完整网格点均值表。

## 4. 可用于本项目

- 可支持：锚定轻中度通气（`VE ≈ 20 L/min`）时呼吸深度已明显增至 `~1.0–1.2 L` 而呼吸频率仍温和在 `~17–21 breaths/min` 区间，防止轻度活动错误报出“大口急促喘气”。
- 不可用于：不可替代耐力运动员高通气极值。
