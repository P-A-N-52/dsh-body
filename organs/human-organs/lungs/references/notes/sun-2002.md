## 1. 能回答的问题

扣除呼吸代谢仪呼吸阀机械死腔后，健康成年人最低运动 `VE/VCO₂` 比值随年龄、性别和身高的预测关系是什么？

## 2. 设计与受试者

- 人群：整合三家实验室 $n = 474$ 名健康成人（`17–78` 岁，含 `n = 28` 动脉血气子队列；年长组含部分吸烟史受试者）。
- 核心实测：
  - 代谢仪呼吸阀自带死腔：MGC 约 `45–65 mL`、SensorMedics 约 `90–110 mL`；自然无面罩呼吸的静息生理 `VD/VT` 显著低于未扣死腔的 CPET 测值。
  - 最低 `VE/VCO₂`（与 `AT` 处比值一致，不受跑台/功率车模态影响）回归方程：
    `27.94 + 0.108 * Age(yr) + (0.97 if Female else 0) - 0.0376 * Height(cm)`。

## 3. 局限与不可推论边界

- 原文聚焦运动中最低 `VE/VCO₂`，未给青年健康人动脉导管各负荷点 `VD/VT` 与 `VE/VO₂` 完整分段矩阵。

## 4. 可用于本项目

- 可支持：说明自然呼吸生理死腔（或等值通气氧当量）在 `VT` 扩张时随 `VD/VT` 下降而改善，校准 `deadSpaceFactor` 与热/运动通气需求解释。
- 不可用于：不可将未扣面罩死腔的静息 `VD/VT ≈ 0.34` 原封不动强加到高 `VT` 运动上。
