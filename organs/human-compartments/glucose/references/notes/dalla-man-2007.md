## 1. 本笔记回答的问题

健康成人餐后平均模型中，可及池葡萄糖质量如何按表观分布体积换算成血浆葡萄糖浓度；`V_G` 的单位和量级是什么。

## 2. 设计、人群与刺激

- 设计：对 204 名正常人的三重示踪混合餐均值数据建立平均模型；另有 14 名 2 型糖尿病患者用于扩展。本文不是本项目模型的独立验证集。
- 正常组：年龄 56 ± 2 岁，体重 78 ± 1 kg；性别构成、空腹时长和前一餐未在本文报告。原句未标年龄和体重的 ± 类型，不能自行写成 SD 或 SEM。
- T2D 扩展组：14 人，年龄 57 ± 3 岁，体重 91 ± 5 kg；不把该组参数用于当前健康基线模型。
- 刺激：混合餐含 `1 ± 0.02 g/kg` 葡萄糖，使用 `1-13C`、`6,6-2H2`、`6-3H` 葡萄糖三重示踪；± 类型未标。餐组成、体积与能量未在本文报告。这里是葡萄糖，不是未区分成分的总碳水。

## 3. 测量与模型定义

原文以三重示踪和示踪剂—示踪物比率钳制获得准模型无关通量，再以 forcing-function 与非线性最小二乘识别各单元过程；整体是均值模型，不是个体预测模型。

p.1741 §III.A 与式 (1)：

- `G_p`、`G_t`（mg/kg）分别是血浆和快速平衡组织、慢速平衡组织中的葡萄糖质量。
- `G`（mg/dL）是血浆葡萄糖浓度。
- `V_G` 是按体重计的葡萄糖分布体积（dL/kg）。
- 原文关系为 `G = G_p / V_G`。换算为以 g 为单位的可及池绝对质量时，`massG = concentrationMgDl × volumeDl / 1000`。

`V_G` 不是血浆体积、瘦体重归一化值、总体水或细胞外液的直接测量。本文没有报告该常数单独的测量/估计方法、是否由参考文献固定、精度或个体间 SD。

## 5. 当前实现只借什么

- 只借定义与量级：`apparentDistributionVolumeDl = 1.88 × referenceBodyMassKg`。
- 当前 75 kg 是项目固定边界，不是原文的 78 kg；对应表观体积 141 dL。
- 当前 90 mg/dL 是工程基线；对应可及池质量 `90 × 141 / 1000 = 12.69 g`。这不是血浆内实际葡萄糖质量。
- 参数状态保持 `design`、`source: SRC-DALLAMAN-2007`。不能称 `fitted_dev` 或 `validated`。

## 6. 不能推出

- 不能从 `V_G` 单独推出 60 min 表观清除半时、20 min 小肠碳水吸收半时、90 mg/dL 基线或 75 kg 体重。
- 不能把血浆 + 快速平衡组织的可及池改写成“血浆体积”“全身水量”或“直接实测全身葡萄糖”。
- 不能用原文葡萄糖刺激替代任意混合碳水的消化、吸收效率或营养组成。
- 单室质量 + 固定清除不能复现原文两室葡萄糖动力学和胰岛素依赖处置。
- 平均模型中的方向或量级一致不等于本项目已拟合、独立验证或适用于个体/疾病状态。

## 8. 后续核对：胰岛素与肾糖结构（2026-11-23）

本次直接读取公开 PDF 页面图像和 layout 文本，核对 p.1743 Table I、p.1745 §III.C.4–5 及式 (26)–(27)。原文链接仍为 https://isbgroup.eu/files/Dalla%20Man%202007.pdf 。

### 8.1 表格勘误

p.1743 Table I 的 T2D `V_G` 图像清楚显示为 **1.49 dL/kg**。本笔记先前版本误记为 1.59，已更正；正常组 1.88 不变。本文其他 T2D 参数不进入当前正常组模型。

### 8.2 胰岛素结构（只作背景）

- p.1742 §III.B 与式 (3)：胰岛素有血浆和肝两个隔室，肝和外周均有清除；这不是当前单相对信号的两室复现。
- p.1744 §III.C.4 与式 (26)：分泌响应包括葡萄糖变化率和葡萄糖水平，分泌阈值设为基础血糖以维持基础稳态。
- p.1744–1745 §III.C.3：利用分为胰岛素非依赖的中枢神经/红细胞项与胰岛素依赖的非线性远端作用。当前聚合清除缩放不复制这些分区。
- p.1748 Discussion：模型是 mean model，且未纳入胰高血糖素等反调激素。

这些段落只支撑“葡萄糖驱动胰岛素信号、胰岛素再影响葡萄糖利用”的结构方向，不支持当前 0.02 增益、10 min 半时、5 倍上限或线性清除缩放的数值。

### 8.3 肾糖排泄

p.1745 §III.C.5 式 (27)：

```text
E(t) = k_e1 × [G_p(t) − k_e2]   if G_p(t) > k_e2
     = 0                        if G_p(t) <= k_e2
```

- `E` 在式 (1) 中是 mg/kg/min 的肾糖排泄通量。
- `G_p` 是 mg/kg 的血浆 + 快速平衡组织葡萄糖质量，不是 mg/dL 浓度。
- `k_e1` 在正文中称为 glomerular filtration rate，单位 `min^-1`；不能改写为 mL/min 的实测 GFR。
- `k_e2` 是 mg/kg 的肾糖阈。

Table I 正常组：`k_e1 = 0.0005 min^-1`，`k_e2 = 339 mg/kg`；T2D 分别为 0.0007、269。原文没有给这两个正常组常数单独的精度、± 类型或个体间离散度，不能声称直接人体测量或独立验证。

若当前可及池浓度为 `C mg/dL`，则 `G_p = C × 1.88 mg/kg`。因此正常组阈值对应约 `339 / 1.88 = 180.32 mg/dL`，只是单位换算，不是另选一个临床阈值。每轮克数请求可写为：

```text
requestG = max(0, C × 1.88 − 339)
           × 0.0005 × referenceBodyMassKg × dtMin / 1000
```

这是原文质量通量形式，不含尿水体积、尿渗透压或 mL 尿量，不能据此计算渗透性利尿。p.1742 式 (2) 前还说明正常基础状态肾糖排泄为零。

当前实现若采用这些表格值，应标为 `prior` / `development`：它们是已发表平均模型的参数锚点，不是本项目的拟合或验证。固定 75 kg、轮次请求—结算和与现有单室模型的连接仍是 `design`。
